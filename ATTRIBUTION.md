# Data Attribution

Display these credits when using data returned by the GB Name Index:

- Contains OS data &copy; Crown copyright and database rights Ordnance Survey [year]. Use the copyright year for the OS data edition. OS Open Names is available under the [Open Government Licence v3.0](https://www.nationalarchives.gov.uk/doc/open-government-licence/version/3/).
- Overture Maps Foundation, overturemaps.org. Overture Places is published under CDLA-Permissive 2.0 and Apache 2.0, depending on source. Follow the [Overture attribution guidance](https://docs.overturemaps.org/attribution/) and current [Places licensing details](https://docs.overturemaps.org/guides/places/).

Overture's provider-level licenses can vary. The current Places guide states that the theme does not include OpenStreetMap data; check the current Overture terms when using a newer release.
